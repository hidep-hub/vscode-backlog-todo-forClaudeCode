# BT-285 カラーモード・ワークスペーステーマ設計

## 目的

Backlog Dashboard の現行オレンジ系ブランド表現と単一アクセント色の設定を廃止し、閲覧環境とワークスペースに応じて一貫した配色を選べるようにする。

## 操作仕様

### 通常表示

ヘッダーと設定パネルのテーマ選択は、常に次の3択とする。

| 値 | 動作 |
| --- | --- |
| `dark` | Dark Blue を既定とするダーク配色を適用する。 |
| `light` | Light Blue を既定とするライト配色を適用する。 |
| `system` | OS の `prefers-color-scheme` に追従し、Dark Blue または Light Blue を適用する。 |

初期値は `system` とする。これにより既定色は青系となり、現行のオレンジ系ブランド色を使わない。

### ワークスペース表示

プロジェクトフィルタで、実ワークスペースを持つプロジェクトを1件選択している間だけ、テーマ選択に `Workspace` を加える。

- `Workspace` を選ぶと設定ダイアログを開く。
- ダイアログでは14個のプリセットとカスタム色を表示する。
- プリセットまたはカスタム色を選ぶと、対象ワークスペースのテーマとして保存・即時適用する。
- Workspaceテーマが保存済みの間は、そのワークスペースを選択した際に `Workspace` を選択状態にする。
- `Dark` / `Light` / `System` を選べば、その表示中だけグローバルテーマに戻せる。全体表示では必ずグローバルテーマを用いる。
- Inbox のように実ワークスペースを持たないプロジェクトには `Workspace` を出さない。

## プリセット

webslide のテーマ設計を参考に、ライト・ダーク各7色を提供する。

| Light | Dark |
| --- | --- |
| Blue, Teal, Indigo, Plum, Forest, Crimson, Slate | Blue, Teal, Violet, Amber, Rose, Lime, Slate |

プリセットはアクセント色から背景、面、カード、文字、境界線、タグ、バッジ等のCSS変数を派生させる。文字と背景のコントラストを優先し、任意色でも画面全体の意味色を壊さない。

カスタム色はカラーピッカーで指定する。現在の実効モード（dark/light）を土台にして派生パレットを生成する。

## 永続化

ブラウザの `localStorage` キー `backlog-dashboard-settings` を使う。

```json
{
  "theme": "system",
  "workspaceThemes": {
    "backlog-todo": { "preset": "dark-teal" },
    "webslide": { "custom": "#7c5cff", "mode": "dark" }
  }
}
```

キーは画面に表示するプロジェクト名ではなく、可能な限り `workspace.file` に相当する安定した識別子を使う。現行のボード応答では表示名とfile名が一致しているため、フロントエンドではプロジェクト名をキーとする。将来APIがfile値を明示した場合はそちらへ移行する。

## 互換性とアクセシビリティ

- 旧設定の `accent` は読み込み時に無視しても画面を壊さない。ワークスペーステーマへの自動移行は行わない。
- `matchMedia('(prefers-color-scheme: dark)')` の変更を監視し、System選択中は再読み込みなしで反映する。
- OSテーマ設定を利用できない環境ではダークをフォールバックとする。
